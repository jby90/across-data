# 大模型数据出站说明（S8）

默认 `CYSH_LLM_REDACTION=on`。所有模型 HTTP 请求经过 `app/analysis/llm.py::post_model`，包括聊天事实抽取、检索规划、分析、独立结论核验、评测、翻译、文件相关性分类、图谱抽取和图谱语义核验。

## 发出与保留

- 会发出完成任务所需的提示词、已脱敏业务事实、候选条款和官方原文片段、JSON Schema。**脱敏不等于数据不出境**；车型、业务场景等未命中规则的内容仍可能发出。
- 规则保护邮箱、常见手机/电话格式、身份证/部分证件格式、VIN、中国车牌、IPv4/IPv6、银行卡样式长数字；企业全称与租户配置的项目代号/客户名称也被替换。规则识别不能保证识别所有自然人姓名、商业秘密或各国所有标识格式，敏感资料应配置词表或使用受控本地模型。
- 占位符映射只保存在单次调用的内存内；模型返回后本地还原，再运行原有引文、数字、语义和来源校验。还原不会补字、替换官方原文或改变人工审批状态。后续调用再次通过出站脱敏，不会把已还原信息直接转发。
- 原始用户输入、法规、引用证据与历史审批继续保存在原有数据库/归档中；不批量改写旧数据。界面和导出展示的还原结果仍受原有权限控制。

## 企业词表

管理端“企业管理 → 配置脱敏词”可维护每企业最多 100 个词，每项 2–200 字符。企业全称自动加入，不必重复。企业管理员也可调用 `PATCH /api/user/organization/redaction`，只能设置本企业；平台管理员可设置任一企业。配置变更保存历史审计，新的调用读取配置。

分析后台任务重新加载任务所属企业的词表，不依赖浏览器会话。并发调用的映射相互隔离。

## 审计与失败

`llm_call_audit` 只保存调用 ID、时间、租户、用途、模型、HMAC-SHA256 输入哈希、脱敏模式/命中数、用量和耗时，**没有提示词、原始输入、输出、映射或密钥列**。同一调用有 started 和结果两个追加记录，用量只记在结果行，汇总时不能按行数当调用数。

发送前必须成功提交 started 审计；审计不可用则不发送。发送后审计失败则拒绝使用返回结果，保留 started 记录供排查。网络失败、HTTP 错误、格式错误均有结果状态；进程异常退出时可能只有 started，不能把它计为成功。数据库触发器禁止更新/删除审计行；有记录时迁移降级拒绝删表。

## 本地模型与开关

通过受控环境变量配置 OpenAI 兼容端点，例如 `CYSH_LLM_BASE_URL=http://127.0.0.1:8001/v1`，以及对应的 `CYSH_LLM_MODEL`、`CYSH_LLM_API_KEY`。本地服务不验证 Key 时可给 Key 设置无敏感性的本地占位值；不要把真实外部 Key 配给不可信端点。

服务可接 vLLM、Ollama 等兼容端点；未在本阶段安装或宣称已验证这些模型的质量/性能。网络地址、TLS、鉴权和实际模型可用性由部署配置控制，管理端不能在线改代码或模型端点。

只有运维环境变量可将 `CYSH_LLM_REDACTION=off`，关闭后仍保留模式及调用审计，原文可能出站。不要在生产中无评估关闭。默认配置为 on，未增加 UI 关闭按钮。
