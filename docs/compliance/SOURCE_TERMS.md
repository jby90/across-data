# 法规来源使用条款登记

每个官方来源站点,在**抓取前**登记其使用条款,并由法务确认能否商用与再分发。
未登记或状态为"待确认"的来源,不得抓取入库用于对外展示全文;只允许内部评估。

## 规则

1. 抓取程序必须读取并遵守 `robots.txt`,限速,记录 User-Agent 与联系方式。
2. 保留官方原文、来源 URL、版本、获取时间和内容哈希。
3. 付费资讯场景默认只展示引用片段加原文链接;展示全文需本表"允许展示全文"为"是"。
4. 官方站点条款发生变化时,更新本表并重新评估已入库内容。
