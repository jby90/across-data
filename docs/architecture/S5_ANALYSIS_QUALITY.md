# S5 分析质量与真实评测

## 原文选择与验证

分析请求包含条款完整原文的编号句段。模型只选择 `clause_id`、连续的整数 `sentence_ids`、用户事实键和法律规则，不生成引文、法规名称或法律条号。服务端通过原文起止偏移截取逐字引文，绑定法规、版本、事实原话和原文 SHA-256。引文不能跨条款拼接，过短片段不能补字，来源隔离和原有数字、币种、日期校验保留。

报告引用和结论JSON均保存 `sentence_ids`、`quote_start/end`、`source_text_sha256`、`selection_version`。旧引用保持原样，新增字段为空，不追填猜测的来源。中文法律规则由模型提炼；逐字依据保留原语言，完整机器译文仍在法规库单独核对，不能把中文分析当作原文译文。

检索采用同一套国别约束与来源过滤，在条款正文中匹配维度词，优先考虑解析出的章节标题。法规标题只作低权重辅助，不能单靠标题让无关正文进入候选。没有国家码、法规名或条号成功特判；当前仍是确定性多语言词法检索，尚非语义召回保证。

## 稳定性与失败边界

- S5基线 `temperature=0`，具体模型、提示词、温度、超时仍读取激活工作流的S4白名单配置。
- JSON格式异常最多两次请求；Schema/事实键异常最多两次生成。网络、截断、Schema异常分类记录，已知失败请求Token也计入用量。超时由节点整体时限约束。
- 证据退回最多两轮，携带具体错误和同一批完整编号原文。不得为凑完整度编造条款。
- 无可用候选法源的维度标记 `source_gap`，可形成 `partial_sample`。已有候选但模型不能给出有效结论，或格式、网络、数字、证据选择仍失败，标记 `analysis_error`，任务失败；保留失败记录和已通过结论，不作为可交付报告导出。
- 修改失败报告的文字会追加版本，并继承 `analysis_failed`，不能通过编辑解锁Word/PDF。
- “程序核验通过”只证明逐字来源与数值约束，不证明法律适用已被人工审定。

输出约束要求每维度提炼至多三条最直接规则，保留主体、触发条件、例外和边界，不复述业务事实，不借其他句子补数值，避免冗长响应截断。有效性未知、来源受损或人工复核待核对的状态均不自动改变。

## 评测口径

冻结题集在 `backend/app/analysis/evaluation_cases.json`：32题，覆盖既定五国与八维度，包含事实、原文定位、原文哈希、官方归档来源和期望结论要点。它是根据归档资料建立的工程来源标注集，未经人工复核，不是人工金标准。埃及受损OCR标注保留问题说明；不解除隔离，不根据跑分修改期望条款。

1. `recall@5`：现有检索流程前五项是否命中期望法规和条款，并用条款ID区分同名文件、附表同号条款及版本。标注对应原文缺失或哈希变化时记为来源漂移，不能静默沿用。
2. 引文忠实度：所有生成结论中，逐字子串、句段选择及数字/金额/日期校验通过的比例，未通过的结论不被提前从分母剔除。
3. 事实一致性：另一次模型请求对“结论＋所选引文”判断是否完整支持，标记 `llm_judged`。`partial`不计支持；判定失败不计成功，单列Judge覆盖率和错误。

没有生成结论时，相应题显示 `0/0`，不是100%；总体面板同时列出题目完成数、各指标分子/分母和人工复核 `0/32`。未生成结论题可从JSON与逐题表定位。期望结论要点供人工核对，不用关键词出现与否冒充事实一致性。

结果由服务端计算，逐题追加到不可变审计表。管理端GET只读，打开看板不触发模型。POST运行评测仅平台管理员可用；不得用客户端提交的分数覆盖结果。一个批次混用配置或未完成时，脚本拒绝发布完整汇总。

## 运行与保护

真实验证使用独立库 `remediation_s5_20261024`，源于S4最终备份；API `127.0.0.1:18005`，管理端 `127.0.0.1:5185`。评测、试运行均不写原开发库或S4隔离库。原始80份归档复用且只读校验，任务和评测记录仅追加到S5副本。

后端在源码 `backend/` 运行，环境变量设置数据库URL、原归档目录、JWT配置及 `CYSH_LLM_API_KEY`，密钥不写文件。随后：

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 18005
```

管理端开发服务设置 `CYSH_DEV_API_TARGET=http://127.0.0.1:18005`。原S4工作流使用旧引文协议，S5升级仅追加待激活基线，必须显式导入/激活当前协议版本，不能覆盖旧配置或自动改变原激活决定。S5版本之间仍可显式回滚。跨协议回滚需同时回滚代码，不能让旧提示词冒充适配新协议。

在仓库根目录运行；评测账号通过临时进程环境变量 `CYSH_EVAL_EMAIL`、`CYSH_EVAL_PASSWORD` 提供，勿写入脚本或日志：

```powershell
python scripts/stability_p3.py --output docs/reviews/s5-stability.json
python scripts/eval_p3.py --output docs/reviews/s5-evaluation.json
python scripts/analyze_backtracks.py --database-url postgresql://postgres@127.0.0.1:3739/remediation_s5_20261024 --task-ids docs/reviews/s5-stability.json --json docs/reviews/s5-backtracks.json --compare docs/reviews/s5-20261024-backtracks-original.json
python -m pytest -q backend/tests/test_analysis_p3.py backend/tests/review_s1_s2_contracts.py
```

真实连续运行结果和未通过边界见 [S5交付记录](../reviews/S5_ANALYSIS_QUALITY_20261024.md)、[评测报告](eval_report_20261024.md)。人工法律复核保持待核对，S6及之后阶段不因此自动验收。
