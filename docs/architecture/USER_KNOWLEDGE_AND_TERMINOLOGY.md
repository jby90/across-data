# 用户知识浏览与来源术语库

本轮在 `codex/user-experience-legal-terms` 分支实施。保留原有法规、译文、图谱、证据、历史版本与审批记录；新增派生索引，不把自动检查写成人工批准。

## 用户与管理员各看什么

用户按“国家 → 文件类别 → 法规 → 条款”阅读，原文与中文对照并排，全文检索和服务端分页覆盖整份文件。旧接口只返回前 80 条的限制已移除；主题中的引用可以定位到原文所在页及条款。

“合规主题”使用现有图谱中的有效证据关系，提供主题总览、关联要点和对应原文。沿用原有来源隔离、版本选择、逐字证据与语义核验规则，不新增一套法规结论。原来的节点、关系和审批状态保留在管理员图谱。

用户任务接口只提供业务进度、事实、分析、报告和引用。工作流版本、提示词、工具参数、输入输出快照、tokens、内部核验追踪留在管理员接口；用户 SSE 同样不发送工具和模型用量事件。不是仅在页面中隐藏这些字段。

全局重复提示、技术核验横幅和每条引用的重复待核对标签已收起。真实的资料缺口、来源变化、分析失败仍提供对应操作。资料的人工复核信息可以在引用详情中查阅，数据库原状态不变。

参考的成熟产品模式：

- [Practical Law Country Q&A](https://uk.practicallaw.thomsonreuters.com/w-007-7165?contextData=%28sc.Default%29&transitionType=Default)：按法域和问题定位内容，再查看依据。
- [Thomson Reuters 研究工具](https://www.thomsonreuters.com/en-gb/help/practical-law/research-tools)：专题研究与跨法域比较入口。
- [OneTrust DataGuidance 官方说明](https://docs.onetrust.com/en/privacy-professional/tracking-regulations/dataguidance-overview)：按国家、主题组织法规、比较要求及跟踪变化。

仅借鉴信息组织方式，不复制产品内容、商标或界面素材。

## 来源术语库

Alembic `0023` 新增 `legal_term_definitions`，不改写 `glossary_terms`、条款、译文或审批行。

|字段组|用途|
|---|---|
|概念编码、语言、原词、中文译名|核心译名复用；原文概念的具体含义仍由所引法规决定|
|定义原文、中文释义|保留逐字来源；中文是阅读对照或暂译|
|国家、法规、版本、条款 ID|防止串用其他国家、其他法规和历史版本|
|来源类型、URL、条款与版本说明|区分法律定义、监管说明、官方语种对照、国际参考|
|原文哈希、起止位置、指纹|核对来源原文未变化、定义确实逐字存在；重复构建不重复入库|
|登记方式、登记人、时间|区别自动提取、管理员登记、机器翻译；均不代表法律审批|

来源选择依次为：法律自身定义、监管指南或问答、明确登记对应法规的官方其他语种版本、国际参考。通用译名是第五种阅读辅助，不能冒充法律定义。

自动提取只处理显式的定义结构：例如引号术语加 means/includes、法语定义引导语与列表、阿语定义列表。按结构识别后保留原始片段与位置，不补字、不修改来源。未识别的格式保留为资料，不猜成定义。OCR 未完成原文核对、来源隔离、原文哈希异常及失效来源不进入自动定义。

默认读取当前可用版本，沿用来源版本观察记录。历史引用传入明确版本读取对应定义。明确限定“本条”“本章节”的定义按条款或章节范围约束；缺少章节路径时保守限于原条款。不同范围的同名定义不合并成一个法律结论。

官方语种对照需要明确的对应文件 ID；不按相似标题推断两份文件是同一部法律。国际参考标明来源性质，不成为目标国家的法定定义。未取得归档原文的国际定义不预装为已验证来源。

跨国家复用的是概念标识、译名规范、别名、程序和缓存；各国的定义、条件和适用范围分别保存。

## 翻译与校验

翻译前根据条款所属法规、版本、语言和定义范围选词，将命中的原词、规范译法、来源定义和出处传给模型。一般词法匹配支持 PDF 换行及阿语常见附着词，不改原文。车辆硬件中的 controller/processor 不因日常词形相同就强制认定为数据控制者或数据处理者。

翻译后继续使用原有数字、金额、日期、中文占比和完整性校验，并检查规定译法。正确译名出现在别处也不能掩盖“控制器”等错误译法。定义冲突或缺少稳定中文对应的词保留原词；有中文暂译时，界面展示原词、暂译、定义和来源。

中文释义批处理使用 `scripts/render_legal_terms.py`。每项只依据已归档的定义，复用同样的严格校验；合格结果新增行，旧行保留。相同来源的译文复用缓存，已生成的释义不重复付费。脚本设置批大小、调用次数和已知 tokens 预算；预算在每批前检查，最后一批可能跨过 tokens 阈值，调用次数另有上限。失败项保留原词并记录原因，不按成功计数。

管理员在“翻译与复核 → 法律术语”可更新来源定义、补充已归档的权威定义和规定译名。法规文档的条款列表提供“复制条款 ID”。新的登记只替换相同来源定义的当前展示；旧登记和旧审批仍保留。旧词条单列为维护记录，不把旧关键词匹配关系自动提升为来源定义。

## 只确认影响结论的歧义

分析输出可附 `needs_term_interpretation`，必须包含检索到的真实条款 ID、原文中存在的术语、具体疑问和对结论的影响。程序拒绝未绑定的词和已有明确来源定义的常规问题；同一来源下的问题幂等登记到既有解读确认单。

常规译名、来源逐字匹配、数字和格式检查自动完成。不把全部词条、全部机器译文都追加为人工任务。业务事实不足继续走既有 S6 追问，不让用户代替系统寻找法条。人工判断仍针对适用含义冲突、资料无法解释且实际影响结论的问题。

本轮不补写任何人工法律核查结论；既有独立评测的人工核查状态不改变。
