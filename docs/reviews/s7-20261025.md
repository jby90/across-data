# S7 按维度导出与实时进度回归记录

日期：2026-10-25。此阶段使用独立合成演示库与完整备份的恢复副本；原五国开发库未迁移、未改写。机器判断不代表人工法律复核。

## 改动

- Word/PDF 支持 `dimension=D1..D8`；ZIP 包含整份和八个章节，共 9 个 Word 文件。页眉包含对话编号、报告版本、维度、机器处理与待核对声明、免责声明。
- 新报告保存各维度判定矩阵快照；导出历史报告只读取对应版本。旧报告没有矩阵快照时明确提示缺失，不能借用最新任务事实。原章节、证据和审批记录不改写。
- SSE 使用事务内事件表及 PostgreSQL LISTEN/NOTIFY；提交后发布，事件 ID 按提交顺序分配。支持 Bearer 鉴权、租户检查、Last-Event-ID 重放、账号撤销与心跳检查；等待客户端时不占用数据库事务。
- 用户聊天和管理端优先读取 SSE；连接失败继续轮询，重连后恢复推送。事件只包含进度元数据，不包含业务原文或密钥。
- 0018 迁移只新增事件表与索引；有事件历史时拒绝直接降级删除。
