# 知识图谱：全局总览与法规分组并存

日期：2026-10-24；分支：`codex/remediate-s0-s3-s1-s2`。

## 展示方式

管理端与用户端均增加 **全局总览 / 法规分组** 切换，默认进入当前国家的全局总览。

- 总览绘制当前筛选后的全部关系，不再按连接度截取前 300 组，也不按单法规的 36 组分页限制总览。
- 法规分组采用等距网格，各组内的义务、数据类型、罚则节点排布在固定半径内；节点尺寸有上限，避免两部大法规占满画面。国家与监管机构放在上方，共享实体只画一次，保留原始跨法规连线。
- 总览使用固定坐标，无需对全部节点持续运行力导向模拟。保留滚轮缩放、拖拽平移、悬停查看名称和法规节点点击进入细节；也可使用法规选择框直接进入详情。
- 图中 `#01` 等序号仅用于本次布局定位，不是法规编号、条号或法律等级；完整名称保留在节点提示及选择框中。总览使用短标签，避免几十个长法规名称重叠。
- 总览同时显示全部关系数、筛选后数量、实际绘制的原始关系记录数及合并连线组数。同起点、终点、关系类型的证据合并为画线时保留证据记录 ID，并继续以全部原始记录的复核状态决定可作依据标识。
- 进入单法规后仍沿用每页最多 36 组的细节图和完整证据表。由总览进入则返回总览，由分组目录进入则返回目录；两种方式互相切换不触发抽取或审批。
- 分组归属仅用于布局，不把共享实体所在位置推定为新的法律关系。总览没有创建汇总法规、虚拟关系或新的知识库记录。

改动范围仅为共享展示函数、两端图谱组件和页面接入。原始法规、图谱数据、证据、复核状态和报告引用逻辑保持原状。

## 实际验证

| 检查 | 结果 |
| --- | --- |
| 管理端新加坡总览 | 全部 1,231 条；默认隐藏范围外文件后 1,216 条；实际展示 **1,216 条 / 1,051 组连线**，902 个节点、53 个分组（含其他关联） |
| 用户端新加坡总览 | 原有范围包含范围外文件，实际展示 **1,231 条 / 1,066 组连线**，917 个节点、68 个分组（含其他关联）；未改变权限与来源隔离策略 |
| 总览下钻 | 用法规选择框进入 Key Concepts 指南：319 条关系，第 1 页展示 37 条 / 36 组；返回总览后恢复全部筛选后的关系 |
| 保留分组目录 | 切到法规分组仍有 53 组、5 页目录；打开 3 条关系的小法规后返回原目录，再切回总览正常 |
| 两端往返 | 管理端、用户端的总览 → 指南详情 → 返回总览均通过实际浏览器验证 |
| 浏览器错误 | 两端最终 error 日志均为空 |

管理端与用户端数量差异沿用既有范围外文件展示规则，并非关系丢失。后台登录会话到期时按正常流程重新登录；用户端刷新后验证了最新组件。
