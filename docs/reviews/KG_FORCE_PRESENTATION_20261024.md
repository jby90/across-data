# 图谱总览与字号调整（2026-10-24）

## 用户要求与范围

按用户提供的截图，将总览恢复为原来的自由分布/力导向样式，修复小图关系文字过大、旋转重叠的问题。只改展示层，保留法规分组、全部/筛选后/当前展示关系数、证据入口及审批状态。

## 改动

- 用户端与管理端共用 `packages/shared/src/graphPresentation.ts`：总览、分组详情及法规一层关联小图使用同一套力导向和字号规则。
- 总览投影保留筛选后关系端点及独立法规，取消固定网格坐标和 `#01` 名称别名，显示实际法规名称。没有截取前几部法规或删除关系。
- 节点文字 11px，强调/提示文字 12px；节点尺寸设上限，关系统计数字缩至 18px。密集总览按画布宽度限制默认名称数量，悬停提示仍可查看完整名称和关系。
- 关系线默认及强调状态均不铺排文字，避免少于 20 条关系时自动启用旋转文本的旧逻辑。关系名称与合并计数保留在悬停提示及证据明细中。
- 初始缩放根据节点数量调整；保留缩放、拖拽节点、平移与重置入口。减少动效偏好仍受支持。力导向布局的位置会随运行而变化，不代表法律关系变化。
- 国别、法规名称及文档 ID 不参与展示算法的成功特判；现有筛选规则、业务 API 与数据库未修改。
