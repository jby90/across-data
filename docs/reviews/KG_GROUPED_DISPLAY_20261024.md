# 知识图谱按法规分组展示：修改与回归记录

日期：2026-10-24。分支：`codex/remediate-s0-s3-s1-s2`。

## 修改结果

管理端“法规知识图谱”和用户端“法规知识库 → 关系图谱”同步调整：

- 默认显示法规目录，每页 12 组，支持按名称搜索；点击法规后展开其关联图，返回目录即可收起。
- 删除按节点连接度优先截取前 300 组关系的显示策略。展开后每页最多 36 组连线，后续关系通过翻页访问，避免两个大法规占满总览。
- 同时显示当前国家接口加载的全部关系数、筛选后关系数、当前图中展示的原始关系记录数，以及合并后的连线组数。展开时另外显示本法规的全部关系数。
- 同起点、终点、关系类型的多条证据只合并为一条画线，不合并、删除或更新数据库记录；画线保留原始记录 ID 列表。只要有任一记录不能作为正式法律依据，合并线就不会按已核准依据着色。
- 法规分组优先使用法规节点绑定的文件 ID；同名不同文件分开显示，并显示短编号。没有法规节点的关系只按唯一的同条款来源或完全匹配且唯一的法规标题辅助归组；无法可靠归属的关系进入“其他关联（法规归属待定位）”，不根据共享节点的可达性推测归属。
- 跨法规关系可同时出现在双方分组中，全局总数按原始记录计数，不能把各分组数量直接相加当成总数。
- 保留关系类型、节点类型、范围外文件、复核状态筛选。图谱始终加载当前国家和当前权限范围内的完整活跃结果，已复核筛选在前端按原接口的边状态和两端节点状态条件处理，避免把筛选后的数量误称为全部关系数。
- 证据表每页 50 条，仍可查看所选法规的全部原文、条号、语义裁判说明与原有复核状态；返回目录后恢复全部筛选结果。管理端只在进入证据标签时渲染证据表，减少隐藏大表造成的卡顿。原有复核操作保留，本次验证没有执行任何审批操作。
- 切换国家时清除先前法规、目录搜索和分页；切换筛选、法规或节点后重置对应分页。法规属性抽屉跟随所选法规。

所有分组、合并、分页均为前端展示投影。后端接口、模型、解析、抽取、数据库迁移和报告引用逻辑没有改动。没有重新抽取图谱，没有调用模型，没有写入或覆盖原文、证据、审批记录。

## 原文、证据和审批保护核验

在隔离开发库 `remediation_20261023` 中，浏览器回归前后分别用只读、可重复读事务读取 20 张业务表的完整行 JSON，排序后逐表计算 SHA-256。

- 共 **29,230 行**，所有表行数与完整行哈希完全一致。
- `changed_tables = []`，包括原文、文档版本、条款、译文、图谱节点和边、审计记录、工作流配置、报告及引用等保护范围。

这次验证确认展示修改没有改写保护范围内的数据；不构成人工法律复核。现有“待核对”继续保持待核对。
