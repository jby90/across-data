# 用户端法规关系解读

日期：2026-10-27。

## 使用方式

进入用户端「法规知识库 → 法规浏览」，选择国家和法规，在正文上方切换「关系解读」。

- 默认展示当前法规的局部关系；点击节点或选择关联主体查看其直接关联。
- 连线使用中文关系名称。点击连线或下方关系目录查看逐字原文依据、条号、归档版本、官方原文和原有复核状态。
- 「阅读条款与中文对照」跳转到证据所属条款及版本，保留原有术语释义功能。
- 分别显示全部符合展示条件的关系数、已加载数、当前图中关系数和合并后的连线数。一次加载 60 条，可继续加载；目录每页 6 条。
- 同一主体、客体、关系类型的多份证据可合并为一条连线，每份证据仍可从关系目录进入。不同方向和不同关系类型分别保留。
- 与文件节点不直接相连的关系可通过主体选择和目录访问，不补造连线。

## 实现与数据边界

新增只读接口 `GET /api/knowledge/regulations/{document_id}/relations`，支持版本和分页，单次最多 120 条；必须通过用户端鉴权。查询按证据条款所属文档/版本限定，不构建整国管理图谱。

沿用 `active_edge_filters()` 的现有准入规则：排除旧规则抽取、语义核验未通过、引文不匹配、过期/拒绝/被替代记录，以及原文错绑与版面安全隔离记录；额外排除已废止版本、结构关系和不可用端点。不会把旧版本关系挪到新版本展示。

接口采用独立响应白名单，不输出提示词、模型名称、内部诊断、节点任意属性或哈希。管理端完整图谱及现有接口保持原样；旧的用户端整国 `/graph` 接口仍返回 410。

前端关系组件与图形依赖异步加载，只有点击「关系解读」后才请求关系数据。布局是有界的一跳投影，关系类型轮换取样以免某类关系占满；单关系场景使用非退化坐标。适配未知国家、多语言、循环、自环及不连通关系，不含国家/法规/评测题特判。

没有数据库迁移、模型调用、抽取重跑或审批写入。原文、证据、版本及审批状态均沿用现有记录。
