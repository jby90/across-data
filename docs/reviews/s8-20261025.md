# S8 大模型出站脱敏与审计

## 范围

- `app/core/redaction.py`：规则脱敏、企业词表、每调用独立的内存映射；JSON 内容先解析再脱敏，避免带引号的企业名绕过匹配。邮箱句末标点、重叠标识和损坏占位符有回归。
- `app/analysis/llm.py::post_model` 是所有模型请求的唯一 HTTP 边界；翻译、相关性分类、图谱抽取/裁判、检索、分析和评测均接入。翻译已有日期/数字保护机制保留；严格校验前恢复原值，不补字或降低标准。
- 模型调用前后追加审计；不保存提示词、原始输入、返回正文、密钥或映射。开始审计失败则不发请求，结果审计失败则拒绝使用响应。
- 后台流水线按任务所属企业加载名称和脱敏词；请求上下文隔离。管理端企业管理可配置项目/客户词表，企业管理员 API 只能配置本企业；变更历史追加保存。
- 0019 迁移增量新增调用审计表及企业词表字段，审计表禁止更新/删除；历史原文、证据、审批不改写。
