# 对话目标国家被后续回答覆盖：诊断与修复

日期：2026-10-27。

## 诊断

对用户报告的会话做只读检查：最初用户选择突尼斯，助手确认目标国家为突尼斯；后续告知/同意问题的长回答提到另一国家，助手再次确认了目标国家，并覆盖任务国家和标题。检索、分析、编制轨迹均使用覆盖后的国家，因此问题影响分析范围，而非仅标题展示。

旧逻辑仅校验模型抽取片段是否存在于用户原话，未区分“本次评估的目标国家”与其他业务角色的所在地，也未保护已经填写的槽位。通用问答还带有特定国家的法规、机构和期限示例，用户在其他国家的会话中也会看到，存在填写诱导。

## 通用修复

1. 模型请求只提供尚未填写的槽位，响应解析和写入端再次校验允许字段；已填写的国家、车型、场景和业务事实不允许被后续自动抽取覆盖。
2. 提示词明确区分目标国家与接收方、人员所在地或举例国家。保护依赖程序白名单，不依赖模型遵守提示词。
3. 首次国家回答涉及多个已配置国家时要求用户明确选择，不再根据字典顺序选取第一个国家。国家识别遵循配置，无国家或法规特判。
4. 其他空字段被抽取时，仍处理当前问题的回答，避免当前回答丢失。
5. 通用问题和选项收集实际业务事实；移除特定国家法规、机构及预设法定期限。法定义务在分析阶段依检索证据判断。

原话子串检查、后续引文/数字/语义校验、人工核验状态及来源隔离规则保持原有标准。无数据库迁移，无历史记录改写。

## 历史报告处理
