# S12a 工程交付检查

本段交付容器化、字体、导出和入口适配；上线记录、产品说明和总评测另行提交。人工法律复核及法务确认仍未完成。

## 变更

- 两端 Fontsource WOFF2 自托管；PDF 改用 WeasyPrint 70 + Pango/HarfBuzz，注册固定官方提交的三套 OFL 字体。Word 仅声明开源字体名。原文、引文和历史报告快照不改写。
- PDF 支持可选择文本、中文/法文/阿拉伯文和通用 Unicode 方向规则；渲染只允许读取已核验的随包字体，不请求外部资源。单进程串行渲染，线程池避免阻塞 SSE。
- 两端 `/licenses`、版权全文、锁定环境 SBOM；Linux 生产环境另外实采 53 个 Python 包，补足 Windows 环境没有的依赖。许可证选择及人工确认状态如实登记。
- 后端多阶段镜像不携带开发依赖、构建 wheel 缓存或未使用的 Pyphen 字典；空的字典资源目录保留以兼容库初始化。默认在线安装；受限网络可用官方哈希锁定的离线 wheels。
- 前后端和网关 Compose；API/worker 共用原文卷；迁移容器使用所有者，运行服务使用普通 RLS 登录；密钥仅环境注入。运行日志独立轮转。Nginx 动态解析 Docker 服务地址，避免替换容器后仍请求旧 IP。
- 管理端 `/admin/` 基路径、鉴权跳转和双端入口适配；对话切换同步地址栏并防止慢响应覆盖新任务。
- `seed_demo.py` 仅允许独立 `*_demo` 库，保留恢复的真实法规和已有样例/审批。创建演示账号幂等，不伪造报告或补齐法源；密码只经环境变量。

## 修正过的失败与边界

首次导出回归发现 WeasyPrint 70 的 URLFetcher 接口变化，修正后通过。首个离线镜像剔除字典目录后无法导入 Pyphen，保留空资源目录后生产渲染通过；原始许可证与源码未修改。首次替换容器暴露 Nginx 静态 DNS 缓存问题，改成带共享区的动态 resolve 并通过 `nginx -t`。

当前云机实际约 1.6 GiB RAM，部署目标为受登录保护的原型，不等于已经支持 100 人在线、20 个 AI 报告同时执行。标准 Node 多阶段构建文件已提供，本次低配服务器实际采用本机生产构建后的静态镜像；不冒称在本机未启动的 Docker Desktop 上做过全栈测试。

法律文本/OCR 缺口、人工复核和已有失败记录保留。运行与数据保护证明不等于法律结论正确率证明，也不等于 S13 全部验收完成。
